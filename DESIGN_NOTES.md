# HerHealth AI — Professional Feminine Frontend

Updated Streamlit frontend with a photographic hero, three image-led feature cards, section photography, trust strip, soft lavender/peach/white palette, rounded cards, responsive spacing and polished form styling.

Images are linked from Unsplash and require internet connectivity to display. Images are illustrative only and do not depict any specific medical outcome or patient.

Run: `pip install -r requirements.txt` then `streamlit run app.py`.
